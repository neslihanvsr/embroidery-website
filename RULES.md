# RULES.md — Project Development Rules

These rules apply to all work on this project and must be followed by anyone (or any AI assistant) making changes.

1. Always read `PROJECT.md` and `RULES.md` before making changes.
2. Follow the approved project plan documented in `PROJECT.md`.
3. Make the smallest possible change needed to accomplish the requested task.
4. Do not rewrite completed pages unless explicitly requested.
5. Keep the code modular, organized, and easy to maintain.
6. Keep the website responsive across mobile, tablet, and desktop.
7. Optimize for accessibility and SEO.
8. Keep the project easy to migrate to Flask later (see `PROJECT.md` Section 8 and `README.md` Section 6).
9. Explain significant changes before implementing them.
10. Stop after completing the requested phase and wait for approval before continuing.
11. Do not change the folder structure without approval.
12. Do not redesign completed pages unless requested.
13. Do not replace existing components unless requested.
14. Preserve the approved design system across all pages.
15. Ask before introducing new libraries or frameworks.
16. Keep the project compatible with GitHub Pages.
17. Keep the project easy to migrate to Flask.
